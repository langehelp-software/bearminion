New: `npm create bearminion@latest my-site` creates a BearMinion site. It asks for the folder, the site name and its web address, copies the default template, installs and makes the first git commit. `--storybook` adds Storybook, `--yes` asks nothing, and `--no-install`, `--no-git`, `--pm`, `--name` and `--url` cover the rest.
